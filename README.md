# 🌶️ Sistemas Web com Python

> Material visual e interativo do curso rápido **Sistemas Web com Python** da programa AI,
> ministrado pelo **prof. Kelson Almeida**: um curso independente para quem sabe o básico de Python.

**8 encontros de 2h**: o aluno constrói uma Loja do zero como app web de verdade — Flask, Jinja,
SQLite com SQL na mão (Dias 1 a 3, sem IA), agentes de codificação em modo agent-first a partir do
Dia 4 (Claude Code/Codex/Antigravity) e deploy com link público.

| Dia | Encontro | O aluno sai com... |
|---|---|---|
| 01 | Olá, Web! Olá, Flask! | site local com duas páginas e URL própria |
| 02 | Telas que falam com Python | formulário cadastrando dados (Jinja, GET/POST) |
| 03 | Banco de dados de verdade | SQL na mão com SQLite, sem IA |
| 03½ | IA & Agentes (em casa) | leitura, agente instalado e primeira tarefa |
| 04 | A Loja ganha banco | listar + cadastrar produtos com persistência real |
| 05 | Editar, excluir e vender | a Loja completa: CRUD + vendas + faturamento |
| 06 | Login com agentes | feature maior dividida em prompts e homologada pelo aluno |
| 07 | Projeto final: a Estante | sistema de biblioteca do zero, 100% por prompts, com design system moderno |
| 08 | No ar! Deploy + Demo Day | Estante em container Docker no Render + link público + apresentação |

## Stack do material

HTML5, CSS3 e JavaScript puros — sem build, sem npm. Design system compartilhado em `shared/`
(herdado de outro material da programa AI). Documentação viva para IAs em [`context/`](context/) — comece por lá.
