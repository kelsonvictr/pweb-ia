Quem acha o bug?

        
Compara a senha digitada com a senha embaralhada (o hash). Nunca vai ser igual — ninguém entra. 🙃

        
No curso, você lê cada diff antes de aprovar. É isso que separa quem usa IA de quem é usado por ela.

import sqlite3

conexao = sqlite3.connect("loja.db")
cursor = conexao.execute(
    "SELECT nome, preco FROM produtos WHERE quantidade > ?",
    (0,)
)
for nome, preco in cursor.fetchall():
    print(nome, preco)
