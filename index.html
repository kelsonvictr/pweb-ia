DIA · 01 🌐 Olá, Web! Olá, Flask! Como a internet funciona por dentro — e o que o Streamlit escondia de você. Sua primeira página com URL própria. HTTP rotas HTML
DIA · 02 📝 Telas que falam com Python Jinja pra mostrar seus dados na tela e formulários pra receber dados do usuário. GET vs POST. Jinja form 🚧 em construção
DIA · 03 🗄️ Banco de dados de verdade Adeus, TinyDB. Chegou o SQLite: tabelas, colunas e a linguagem SQL — a mesma dos sistemas profissionais. SQL SELECT 🚧 em construção
DIA · 04 📦 A Loja ganha banco Listar e cadastrar produtos direto no SQLite. Reinicia o servidor e os dados continuam lá. 🤯 CRUD 1/2 INSERT 🚧 em construção
DIA · 05 🛒 Editar, excluir e vender O CRUD completo + a tela de vendas com baixa de estoque e faturamento. A Loja inteira, agora na web. CRUD 2/2 UPDATE 🚧 em construção
DIA · 06 🤖 Programando com agentes de IA Claude Code, Codex e Gemini CLI. Especificar, gerar, revisar, testar — o agente constrói o login do sistema. Claude Code login 🚧 em construção
DIA · 07 🏗️ Projeto final — seu sistema Barbearia? Petshop? Brechó? Você escolhe o tema e constrói seu próprio sistema, com o agente de par. seu tema na prática 🚧 em construção
DIA · 08 🚀 No ar! Deploy + Demo Day Seu sistema publicado com link real, testado no celular, apresentado pra turma. E o mapa do próximo passo. deploy demo day 🚧 em construção
